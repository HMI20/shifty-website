# Rosterzo website (Rosterzo)

The marketing site for the Rosterzo shift scheduler: Arabic at `/`, English at `/en/`.
Plain static HTML generated by `build.mjs` with no dependencies.

- `src/` — page templates (`home.mjs`, `pages.mjs`, `plans.mjs`, `faq.mjs`, `demos.mjs`), shared layout and `config.mjs` (links to the app, the live demo and Supabase).
- `assets/` — `styles.css` and `app.js` (menu, pricing toggle, savings calculator, contact form, animated feature demos).
- Build: `node build.mjs` → `dist/`. Preview: `npm run dev` → http://localhost:4300.
- Deploy: Cloudflare Pages builds every push to `main` (build command `node build.mjs`, output `dist`).
- The contact form inserts into the `leads` table of the app's Supabase project (insert-only for visitors; read them in the Supabase Table Editor).
- Prices live in `src/plans.mjs`.
